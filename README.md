# EmotionVerse AI

## Multi-Modal Human Emotion Intelligence for Healthcare and Education

EmotionVerse AI is an AI-based system that detects human emotions using facial expressions captured through a camera. The system uses computer vision and deep learning to identify emotions and provides a risk indication based on the detected emotional state.

## Technologies Used

* Python
* OpenCV
* TensorFlow
* CNN (Convolutional Neural Network)
* FER-2013 Emotion Dataset

## Emotions Detected

* Happy
* Sad
* Angry
* Fear
* Surprise
* Disgust
* Neutral

## System Workflow

Camera Input → Face Detection → Emotion Detection → Risk Analysis → Risk Result

## Main Components

1. **Face Detection** – Detects a human face using OpenCV.
2. **Emotion Detection** – Uses a CNN model to recognize facial emotions.
3. **Risk Engine** – Processes the detected emotional information and produces a risk indication.
4. **Camera Interface** – Provides real-time emotion detection through the webcam.

## Project Objective

The objective of EmotionVerse AI is to develop an intelligent system that can analyze facial emotions in real time and provide an additional risk indication that can be explored for healthcare and educational applications.

## Project Status

The real-time camera-based emotion detection and risk indication components have been implemented successfully.
